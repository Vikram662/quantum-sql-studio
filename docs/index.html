The MySQL client that stops you before you break production.

Quantum SQL is a free desktop client for MySQL and MariaDB. Browse, edit, query and monitor your databases, with safety checks that catch risky statements before they run.

Download for free View the source on GitHub

Windows, macOS and Linux. Open source under the MIT License.

Everything you open a database client for

One app for day-to-day work, performance checks and schema changes, in the style of HeidiSQL and MySQL Workbench.

Browse and editYour data, without writing SQL

  • Saved connections with colour tags, encrypted passwords and SSH tunnels
  • Object tree for databases, tables, views, procedures and triggers
  • Inline editing that saves when you leave the cell, with undo
  • Table designer with an SQL preview before anything is saved

Write queriesFast, with help when you need it

  • Autocomplete for tables and columns, snippets and query parameters
  • Visual Explain with an index advisor
  • AI assistant that writes and explains SQL, using your own API key
  • Export results to CSV, Excel, JSON, SQL, Markdown or HTML

Stay safeMistakes are caught before they run

  • Environment tags: production sessions are red and ask before every write
  • Safe mode for UPDATE or DELETE without WHERE, DROP and TRUNCATE
  • Safe transactions: review the result, then commit or roll back
  • Dumps and imports to .sql, .sql.gz or .zip with a progress bar

Monitor and tuneSee what the server is doing

  • Live monitor of active sessions, queries per second and slow queries
  • Top SQL with per-statement timings
  • Health advisor for buffer pool, missing keys, lock waits and more
  • Schema compare, ER diagrams and code generators
