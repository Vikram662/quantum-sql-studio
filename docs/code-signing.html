Code Signing Policy

Last updated 14 October 2026

Windows builds are being set up for signing through the SignPath Foundation (application pending). Once approved: free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

  • Only release binaries of this project: the Windows installer and the application executable published on the Releases page.
  • Every signed file is built by GitHub Actions (build.yml) from the source code in the public repository. Nothing built on a personal machine is signed.
  • Third-party components bundled in the installer are open source and listed in THIRD_PARTY_NOTICES.txt.
