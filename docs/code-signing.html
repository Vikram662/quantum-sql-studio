Code Signing Policy

Windows builds are being set up for signing through the SignPath Foundation (application pending). Once approved: free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

  • Only release binaries of this project: the Windows installer and the application executable published on the Releases page.
  • Every signed file is built by GitHub Actions (.github/workflows/build.yml) from the source code in the public repository. Nothing built on a personal machine is signed.
  • Third-party components bundled in the installer are open source and listed in THIRD_PARTY_NOTICES.txt.

Team roles

  • Authors and committers: Vikram662
  • Reviewers (review every pull request from outside contributors): Vikram662
  • Approvers (approve every signing request by hand): Vikram662

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See the privacy policy.
