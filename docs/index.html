Quantum SQL

A free, open source desktop client for MySQL and MariaDB, in the style of HeidiSQL and MySQL Workbench, for Windows, macOS and Linux. Built with Python, PySide6 (Qt) and PyMySQL.

Download the latest release

Features

  • Session manager with saved, encrypted connections and SSH tunnels.
  • Object tree, table designer, inline data editing with undo, and query tabs with syntax highlighting and autocomplete.
  • SQL dump export and import; grid export to CSV, Excel, JSON, SQL, Markdown and HTML.
  • Live monitor, Top SQL, active sessions and a health advisor.
  • Safety features: environment tags, safe mode for destructive statements, and safe transactions.
  • Visual Explain with an index advisor, schema compare and sync, ER diagrams, code and test data generators.
  • Optional AI assistant that writes and explains SQL using the provider and API key you choose.
